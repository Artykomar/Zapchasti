# Zemazap

MVP-витрина мультибрендового магазина автозапчастей.


Текущий формат: каталог по маркам и категориям, карточки товаров, избранное,
корзина-заявка и сервисные страницы. Публичный frontend читает каталог и
отправляет заявки через Django API; локальные Next.js route handlers работают
как тонкий proxy на `ZEMAZAP_DJANGO_API_URL`.

Локально нужно поднять два процесса:

```powershell
.\.venv\Scripts\python.exe backend\manage.py runserver 127.0.0.1:8000
npm.cmd run dev
```

VIN-пробив и онлайн-оплата не входят в локальный MVP и должны подключаться
отдельно после выбора инфраструктуры, безопасности, домена и платежного
провайдера.
