# Zemazap

MVP-витрина мультибрендового магазина автозапчастей.


Текущий формат: каталог по маркам и категориям, карточки товаров, избранное,
корзина-заявка и сервисные страницы. VIN-пробив и онлайн-оплата не входят в
локальный MVP и должны подключаться отдельно после выбора инфраструктуры,
безопасности, домена и платежного провайдера.
