# Zemazap: чеклист передачи владельцу и банку

## Данные владельца, без которых production не включается

- [ ] ИП/ООО и полное юридическое название подтверждены.
- [ ] ИНН, ОГРН/ОГРНИП, КПП (для ООО), юридический и фактический адреса заполнены.
- [ ] Домен зарегистрирован на реального владельца/юрлицо, DNS и HTTPS настроены.
- [ ] Телефон, email, email для претензий, график и адрес выдачи реальные.
- [ ] Условия доставки, оплаты, гарантии и возврата утверждены.
- [ ] Политика и согласие ПДн утверждены; статус уведомления РКН проверен юристом.
- [ ] Альфа-Банк выдал test/prod API credentials и одобрил сайт.
- [ ] Онлайн-касса/ОФД подключены, налоговый режим и ставки НДС подтверждены бухгалтером.
- [ ] Yandex Cloud, Managed PostgreSQL, Object Storage, Lockbox, WAF и бэкапы созданы.

## Техническая приемка

- [ ] CI зеленый на commit SHA, который будет развернут.
- [ ] Application Load Balancer ведет на Caddy port `8080`; Django/Next ports наружу не открыты.
- [ ] Контейнер `scheduler` healthy по logs и обработал тестовое pending-уведомление.
- [ ] `manage.py check --deploy`, миграции, backend tests, typecheck и Next build проходят.
- [ ] `manage.py check_launch_content` подтверждает 7 опубликованных документов;
  публичные страницы показывают их версии и утвержденный текст, а не fallback.
- [ ] `DATABASE_URL` указывает на Managed PostgreSQL; SQLite блокируется production check.
- [ ] `STORAGE_BACKEND=yandex` и приватный Object Storage настроены; локальное media-хранилище блокируется production check.
- [ ] PostgreSQL проверен на пустой базе и на восстановленной копии.
- [ ] Главная, каталог, карточка, заявка, контакты, юридические страницы, 404 и health работают.
- [ ] Успешный и неуспешный test-платеж подтверждаются server-to-server.
- [ ] Повтор callback безопасен; неверная сумма и неизвестный заказ отклоняются.
- [ ] Полный и частичный возврат не превышают оплаченную сумму.
- [ ] Чек прихода и чек возврата видны в кассе/ОФД; `pending_confirmation` снят
  реальным подтверждением, критические ошибки создают сигнал.
- [ ] В Telegram и logs нет ПДн; карточные данные нигде не вводятся и не сохраняются.
- [ ] Бэкап и rollback проверены, мониторинг и ответственные назначены.

## Публичная банковская проверка

После заполнения реальных реквизитов маршрут `/bank-review` автоматически становится доступен. До этого он возвращает 404, чтобы банк не увидел тестовые заглушки.
